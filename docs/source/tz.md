**Опросник «Паспорт красоты»**\
Описание логики опросника в личном кабинете: структура дерева, правила
ветвления, алгоритм присвоения психотипа\
**1. Общая архитектура**\
Опросник разделён на два этапа. Первый короткий и даёт немедленный
результат, второй --- опциональный и глубокий.

  ---------------- --------------------------------------- -------------- ---------------------------------------------- --
  **Этап**         **Что спрашиваем**                      **Вопросов**   **Результат**                                  
  **1. База**      Пол, психотип, интересующая категория   5              Психотип и набор виджетов ЛК                   
  **2. Паспорт**   Детали по выбранной категории           3--8           Профиль потребления, уточнённые рекомендации   
                                                                                                                         
  ---------------- --------------------------------------- -------------- ---------------------------------------------- --

Между этапами --- экран результата с анонсом Паспорта. Пользователь
может остановиться после первого этапа: кабинет уже настроен.\
Заполненность профиля: база даёт 40%, каждая пройденная категория
добавляет 20%, максимум 100% (база и три категории).\

**3. Алгоритм присвоения психотипа**\
Каждый вариант ответа в вопросах 2--4 размечен одним из значений:

  --------- -------------------------------------------------- -- -- --
  **Код**   **Значение**                                             
  **E**     Эмоциональный                                            
  **P**     Прагматичный                                             
  **L**     Премиальный                                              
  **M**     Ни один вариант не подходит / подходит несколько         
  --------- -------------------------------------------------- -- -- --

**Правила, в порядке проверки**

+----------------------------+----------------------------+---+---+---+
| 1.  Если M встречается два | **Результат**              |   |   |   |
|     и более раза --- тип   |                            |   |   |   |
|     смешанный.             |                            |   |   |   |
|                            |                            |   |   |   |
| 2.  Иначе считаем голоса   |                            |   |   |   |
|     E, P, L. Тип с         |                            |   |   |   |
|     максимумом побеждает.  |                            |   |   |   |
|                            |                            |   |   |   |
| 3.  Если максимум делят    |                            |   |   |   |
|     два и более типа ---   |                            |   |   |   |
|     смешанный.             |                            |   |   |   |
|                            |                            |   |   |   |
| 4.  Если ни одного голоса  |                            |   |   |   |
|     E, P или L ---         |                            |   |   |   |
|     смешанный.\            |                            |   |   |   |
|     **Проверочные случаи** |                            |   |   |   |
|                            |                            |   |   |   |
| **Ответы**                 |                            |   |   |   |
+----------------------------+----------------------------+---+---+---+
| E, E, E                    | Эмоциональный              |   |   |   |
+----------------------------+----------------------------+---+---+---+
| E, E, P                    | Эмоциональный              |   |   |   |
+----------------------------+----------------------------+---+---+---+
| E, P, L                    | Смешанный --- ничья        |   |   |   |
+----------------------------+----------------------------+---+---+---+
| M, M, E                    | Смешанный --- два «не      |   |   |   |
|                            | подходит»                  |   |   |   |
+----------------------------+----------------------------+---+---+---+
| M, E, E                    | Эмоциональный              |   |   |   |
+----------------------------+----------------------------+---+---+---+
|                            |                            |   |   |   |
+----------------------------+----------------------------+---+---+---+
